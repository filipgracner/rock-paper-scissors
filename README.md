# Rock, Paper, Scissors

A simple Python game where the user plays against the computer.

## Game Rules

The player chooses rock (`r`), scissors (`s`), or paper (`p`).

* Rock beats scissors.
* Scissors beat paper.
* Paper beats rock.
* If the player and the computer choose the same option, the result is a tie.

After each round, the number of wins, losses, and ties is updated.

## Requirements

* Python 3 installed.

## Running the Game

Run the following command in the terminal inside the project folder:

```
python .\rock-paper-scissors.py
```
